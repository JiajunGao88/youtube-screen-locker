What this can and cannot block

Deep Lock runs only in JavaScript fullscreen (the player’s fullscreen, not F11). On Windows, Chrome’s keyboard hook can intercept the Windows key, Alt+Tab, Alt+F4, and browser shortcuts such as Ctrl+W. On macOS there is no OS modifier hook, so Cmd+Tab and Mission Control still work; browser shortcuts in fullscreen can be captured.

OS master volume and Ctrl+Alt+Del are handled outside the browser. This extension does not add native messaging or any new install warning.
